# 工具说明

## JSON 格式化

粘贴 tool schema 或例行任务 JSON。美化 / 压缩 / 校验都在本页完成。非法 JSON 会显示解析器错误信息。适合发版前检查 Agent 工具 schema。

## Cron 解释

支持五段字段上的 `*`、`*/n`、`a-b`、`a,b,c`。星期 `0`/`7` = 周日。不是完整的「下次触发」模拟器——用来在写入例行任务前看懂结构、抓笔误。

## SHA256 校验

拖入 zip/二进制；可选粘贴 `SHA256SUMS.txt` 里的期望摘要。不一致 → 不要信任该文件。超大文件受浏览器内存限制。需要 Web Crypto（安全上下文）。

## UTF-8 乱码实验室

若 GBK 等字节曾被当成 Latin-1 解码再显示成 Unicode，「Latin-1 字节 → UTF-8」常能恢复中文乱码。对双重编码无效——若粘贴内容已含 &gt;255 的码点，工具会明确提示。
